Checklist

Login

• Проверить отображение страницы авторизации.
• Проверить наличие поля Username.
• Проверить наличие поля Password.
• Проверить наличие кнопки Login.
• Выполнить вход с валидными данными.
• Проверить успешный вход в приложение.
• Проверить вход с неверным Username.
• Проверить вход с неверным Password.
• Проверить вход с пустыми полями.
• Проверить отображение сообщения об ошибке при неуспешной авторизации.

Products

• Проверить отображение страницы Products после успешной авторизации.
• Проверить отображение списка товаров.
• Проверить наличие названия товара.
• Проверить наличие изображения товара.
• Проверить наличие описания товара.
• Проверить отображение цены товара.
• Проверить наличие кнопки добавления товара в корзину.
• Проверить добавление товара в корзину.
• Проверить изменение кнопки после добавления товара в корзину.
• Проверить удаление товара из корзины со страницы Products.
• Проверить сортировку товаров по названию.
• Проверить сортировку товаров по цене.

• Проверить отображение выбранного товара.
• Проверить отображение цены товара.

• Проверить завершение оформления заказа.
